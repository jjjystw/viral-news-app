# 📱 바이럴뉴스 — 국내 핫이슈 모바일 웹앱 (PWA)

국내 주요 언론사의 공개 RSS를 모아 **바이럴 점수**로 정렬해 보여주는 서버 없는 모바일 웹앱입니다.
GitHub Pages에 올려 두고, **매시간** 뉴스를 다시 모아 자동으로 갱신합니다.
아이폰 사파리에서 열어 **홈 화면에 추가**하면 앱처럼(전체 화면·자체 아이콘) 쓸 수 있습니다.

- 앱 주소: **https://jjjystw.github.io/viral-news-app/**
- 저장소: https://github.com/jjjystw/viral-news-app

## 아이폰 홈 화면 추가

1. 아이폰 **사파리**로 위 주소를 연다.
2. 하단 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 🔥 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `fetch_news.py` | 뉴스 수집 + 분류 + 바이럴 점수 산출 + `data.json`·`index.html` 생성 |
| `template.html` | 앱의 UI 원본(HTML/CSS/JS). 데이터가 들어갈 자리만 비어 있음 |
| `index.html` | **완성품**. 수집된 기사 데이터가 안에 인라인으로 박혀 있음 |
| `data.json` | 같은 데이터의 JSON 버전(다른 앱·분석용) |
| `manifest.json` | PWA 매니페스트(앱 이름·아이콘·standalone 표시) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 홈 화면 아이콘 |
| `make_icons.py` | 아이콘 재생성기(`pip install pillow` 필요, 평소엔 불필요) |
| `validate_build.py` | 빌드 결과 검증기(빈 제목·NaN 점수·깨진 날짜·중복 링크 등 확인) |

## 자동 갱신

매시간 `python3 fetch_news.py` 를 실행해 `index.html`·`data.json` 을 다시 만들고, 바뀐 내용을 이 저장소의 `main` 브랜치에 커밋·푸시합니다. GitHub Pages는 몇 초 안에 새 화면을 서빙하므로 앱을 열면 항상 최신 뉴스가 나옵니다.

- 앱 상단의 `LIVE` 배지 옆에 `11월 22일 (일) 22:07 기준` 처럼 마지막 갱신 시각이 찍힙니다.
- 데이터가 3시간 넘게 갱신되지 않으면 앱 위에 **"데이터가 오래됐어요"** 배너가 떠서 갱신이 멈춘 것을 바로 알 수 있습니다.
- 갱신 주기를 바꾸거나 멈추려면 이 저장소를 갱신하는 자동화 설정에서 조정합니다.
- GitHub Actions로 옮기고 싶다면 `python3 fetch_news.py` 를 실행하고 `index.html`·`data.json` 을 커밋·푸시하는 워크플로를 `.github/workflows/` 에 추가하면 됩니다(매시 정각 cron: `0 * * * *`, `permissions: contents: write`).

## 로컬 사용법

```bash
# 1) 뉴스 새로 모으고 앱 다시 만들기 (보통 20초~2분)
python3 fetch_news.py

# 2) 데이터는 그대로 두고 화면만 다시 빌드
python3 fetch_news.py --rebuild

# 3) 수집 시간창 바꾸기 (기본 48시간)
python3 fetch_news.py --hours 24

# 4) 결과 검증
python3 validate_build.py
```

## 수집 소스 (13곳)

- **언론사 공개 RSS**: 연합뉴스(최신·사회), 경향신문, 조선일보, 노컷뉴스, 오마이뉴스, 머니투데이
- **구글뉴스 한국어 RSS 경유**(구글뉴스가 원문 언론사 주소로 연결): SBS 뉴스, KBS 뉴스, MBC 뉴스, 한겨레, 구글뉴스 헤드라인, 구글뉴스 사회

SBS·KBS·MBC는 자체 RSS 공개를 중단해서, 구글뉴스의 `site:` 검색 피드를 씁니다.
기사 링크는 구글뉴스 리다이렉트가 아니라 **원문 언론사 주소**로 해석해서 저장합니다.

## 바이럴 점수 (0~100)

세 지표를 가중 합산합니다.

| 지표 | 보는 것 | 비중 |
| --- | --- | --- |
| **확산도** | 같은 사안을 동시에 다룬 매체 수(제목 토큰 IDF 유사도로 묶음) | 42% |
| **속보성** | 속보 여부 + 발행 후 경과 시간 | 27% |
| **화제성** | 반응·감정 키워드, 인용·숫자·최상급 표현, 대통령/사퇴/참사 같은 임팩트 단어, 카테고리 | 31% |

- 매체 수가 3곳 이상이면 가점, 5곳 이상이면 추가 가점.
- 같은 사안을 다룬 여러 매체 기사는 **대표 1건으로 합쳐** 피드가 중복되지 않게 합니다(합친 뒤 카드에 "N개 매체" 표시).
- 점수 근거는 카드의 `바이럴 포인트`, 상세 시트의 세부 지표 막대, `확산도 100 (매체 9곳) · 속보성 89 …` 형태의 설명으로 함께 노출됩니다.

## 카테고리 자동 분류

| 카테고리 | 기준 |
| --- | --- |
| 🚨 사건사고 | 사고·화재·사망·검거·재판·수사 등 사건 키워드 |
| 🤯 얼탱없음 | 황당·갑질·민폐·막말·횡령·먹튀·커닝 등 어이없는 정황 |
| 🥹 감동 | 감동·미담·선행·기부·기적·전원 구조 등 |
| 💬 이슈 | 그 밖의 화제·정치·경제 |

정치 절차(탄핵·면직·공방)는 사건사고가 아니라 이슈로, 스포츠 경기 결과는 감동/사건사고가 아니라 이슈로 보정합니다.

## 앱 기능

- 상단 고정 헤더(데이터 기준 시각 · LIVE · 새로고침), 최대 폭 430px 중앙 정렬
- 정렬 토글: **바이럴 순위 / 최신 속보순**
- 시간 필터: 전체 · 속보 · 1시간 이내 · 3시간 이내 · 오늘 (연 시각 기준으로 실시간 계산)
- 카테고리 탭: 🔥 전체 HOT · 🚨 사건사고 · 🤯 얼탱없음 · 🥹 감동 · 💬 이슈
- 뉴스 카드: 순위(1~3위 강조), 점수 배지, 카테고리, 언론사·경과 시간·매체 수, 제목, 한 줄 요약, 바이럴 포인트, 원문 링크, 북마크
- 상세 바텀시트: 요약, 왜 바이럴인지, 확산도/속보성/화제성 막대, 태그, 원문 바로가기·북마크·공유
- 하단 탭바: **랭킹 / 시간대별 / 속보 / 저장함** (북마크는 localStorage에 저장)
- 홈 화면 앱(PWA): standalone 표시, 상태바 black-translucent, 자체 아이콘

## 참고

- 수집기는 표준 라이브러리만 사용합니다(별도 설치 불필요). 아이콘 재생성에만 Pillow가 필요합니다.
- `.cache/`에는 구글뉴스 링크 해석 결과와 페이지 요약이 캐시됩니다. 두 번째 실행부터 훨씬 빨라집니다(저장소에는 올리지 않음).
- 데이터가 3시간 넘게 지나면 앱 상단에 "데이터가 오래됐어요" 배너가 뜹니다. Actions가 멈추면 이 배너로 알 수 있습니다.
